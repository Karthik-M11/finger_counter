# Finger Counter
A real-time hand tracking application that counts the number of fingers shown to your webcam using computer vision and MediaPipe’s Tasks API

### Download the MediaPipe hand model
Download the MediaPipe hand model from [here](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/index#models) and place the hand_landmarker.task file in the same folder as the main file
